# KanPaint v0.4

## Trọng tâm: Skin Retouch không phá hủy ảnh gốc
V0.4 thêm Retouch Layer riêng. Khi Output là **Retouch Layer — non-destructive**, Apply không thay pixel của layer ảnh gốc. KanPaint tạo một pixel layer trong suốt nằm ngay phía trên ảnh gốc.

Retouch Layer lưu:
- ID ảnh gốc.
- Bộ thông số Skin Retouch.
- Mask dưới dạng PNG alpha nén.
- Kích thước nguồn.

Khi chọn lại Retouch Layer và mở Skin Retouch, KanPaint ẩn tạm layer hiệu ứng, dựng preview trên ảnh gốc và cho chỉnh lại thông số/mask. Apply cập nhật chính layer hiệu ứng đó.

## Output
- Retouch Layer — non-destructive: mặc định, nên dùng.
- Pixels — destructive: giữ workflow V0.3 khi cần ghi trực tiếp vào ảnh.

## Công cụ
- Use Selection: biến selection hiện tại thành retouch mask.
- Clear Mask: xóa mask đang làm việc.
- Edit Active Retouch: mở lại Retouch Layer đang chọn.
- Hold: Before: giữ chuột để xem ảnh gốc.

## 4 rủi ro đã chặn
1. Core phình to: chức năng V0.4 tiếp tục ở extension JS/CSS riêng.
2. 4K/8K lag: preview proxy; full-resolution chỉ render khi Apply.
3. Da nhựa: edge-aware smoothing + Detail Preserve + Texture/Pores + Grain Size.
4. Script: sandbox + allow-list API + giới hạn thời gian/dung lượng.

## Giới hạn V0.4
Retouch Layer là pixel effect layer có metadata chỉnh lại được trong KanPaint, chưa phải adjustment layer chuẩn PSD. Xuất PSD/OpenRaster sẽ rasterize hiệu ứng theo khả năng exporter của OpenShop.
