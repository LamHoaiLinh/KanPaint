# KanPaint v0.5

## Skin Retouch mask workflow
V0.5 hoàn thiện phần mask theo hướng quen thuộc với Photoshop/Photopea:

- **Show red mask overlay**: lớp phủ đỏ chỉ để xem vùng tác động, không được export.
- **Alt + Brush**: xóa mask thay vì thêm mask.
- **Invert Mask**: đảo vùng tác động.
- **Feather 0–60 px**: làm mềm biên mask bằng blur hai lượt O(N).
- **Density 0–100%**: giảm mức ảnh hưởng toàn mask mà không phá mask thô.
- **Before / After Split View**: so sánh ảnh gốc và preview bằng thanh chia kéo ngang.
- Feather/Density được lưu cùng metadata Retouch Layer để mở lại chỉnh tiếp.

## Non-destructive
Retouch Layer vẫn là output mặc định. Layer lưu ID ảnh gốc, thông số retouch, mask PNG alpha và mask settings. Khi mở lại, KanPaint tái dựng preview từ ảnh gốc thay vì cộng dồn chỉnh sửa lên ảnh đã retouch.

## Hiệu năng
- Preview retouch giới hạn khoảng 1.2 MP.
- Mask overlay giới hạn khoảng 0.9 MP.
- Split comparison giới hạn khoảng 2 MP.
- Apply mới render full-resolution.

## Script API bổ sung
```js
await kan.skin.maskInfo();
await kan.skin.invertMask();
```

## Giới hạn
Retouch Layer của KanPaint vẫn là pixel effect layer có metadata riêng, chưa phải Photoshop adjustment layer chuẩn PSD. Khi xuất định dạng ngoài KanPaint, hiệu ứng có thể được rasterize.
