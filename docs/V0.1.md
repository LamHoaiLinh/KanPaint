# KanPaint 0.1

KanPaint 0.1 là bản bắt đầu sử dụng chính thức. Các số 0.2–0.5 trước đây chỉ là prototype trong giai đoạn xây nền.

## Phạm vi 0.1
- Giao diện xanh lá pastel.
- Layer export + alpha trim + ZIP.
- Skin Retouch non-destructive.
- Automation API v1.
- Script Library, Script Templates, Script Events và Hotkeys.
- Batch Runner.
- Help Center tích hợp.

## API compatibility
Automation API bắt đầu ở 1.0. Script nên ưu tiên namespace `kan.v1`. Alias ngắn `kan.layers`, `kan.selection`, `kan.filters`... được giữ để script hiện tại dễ đọc.

## Lưu ý
`layers.trim()` rasterize layer đang xử lý thành một pixel layer đã trim. Với asset game đây là hành vi mong muốn; với tài liệu cần giữ vector/text thì nên duplicate layer trước hoặc chỉ dùng Export Layers > Auto Trim.
